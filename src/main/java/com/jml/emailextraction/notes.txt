✅ Option 1: Using Microsoft 365 (Outlook) + Graph API + Webhooks
If you're using a Microsoft 365 email address (like assist@yourdomain.com), this is the most scalable, secure, and cloud-native way:

🔧 How it Works:
Register your app in Azure Portal

Use Microsoft Graph API to access emails (no need for IMAP).

Set up Graph change notifications (webhooks) for:

MailFolders('Inbox')/messages

You’ll receive a webhook payload on new incoming email

Your server (Java/Spring) receives that event → fetches the full message → parses and stores it.

Graph Webhook Docs

Event notifications sent to your HTTPS endpoint
